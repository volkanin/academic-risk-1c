# Сервис раннего предупреждения об академическом риске студентов

Выпускная работа по программе профессиональной переподготовки «Инженер-архитектор в сфере искусственного интеллекта» (Университет Иннополис).

Автор: Leonid Volkanin.

## О проекте

Сервис на основе данных информационной системы вуза 1С:Университет оценивает вероятность отчисления студента в предстоящем семестре, объясняет, какие обстоятельства привели к оценке, и возвращает результат в информационную систему для сотрудников деканата и кураторов. Сервис не принимает решений за сотрудника, а формирует обоснованный список студентов для внимания.

Модель обучается на открытых наборах данных учебной аналитики (UCI Predict Students' Dropout and Academic Success, OULAD). Интеграционный слой демонстрируется на синтетическом контингенте, сгенерированном по структуре витрин 1С:Университет. Реальные персональные данные студентов не используются.

Ключевое методологическое требование: признаки формируются строго по сведениям, известным на дату наблюдения (срез на дату), что исключает утечку будущих данных в обучение и оценку.

## Быстрый старт

Инструкция будет дополнена по мере готовности компонентов (см. deployment/).
