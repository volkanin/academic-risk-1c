# Карта соответствия: предметные поля и объекты метаданных

База: 1С:Университет ПРОФ, конфигурация УниверситетПРОФ_2_2, версия 2.3.2.28
(выгрузка C:\work\inno_grad\config). Карта составлена по файлам выгрузки
метаданных и подтверждена прогонами сервиса на тестовой копии базы
(28.11.2026): для каждого источника указаны фактические данные. Реализация
в расширении src/1c_ext, контракты методов в docs/1c_enhancements_tz.md.

Перечни значений справочников это данные, а не метаданные; метод
GET /reference отдаёт их внешнему сервису: типы приказов, виды приказов,
аналитика приказов, отметки, виды контроля, формы обучения, специальности,
состояния физических лиц.

## 1. Студент (dim/students)

Источник: регистр сведений СостояниеСтудентов (срез последних на дату)
соединяется со справочниками ФизическиеЛица и ЗачетныеКниги.

| Поле | Источник | Примечание |
|---|---|---|
| student_id | СостояниеСтудентов, измерение ФизическоеЛицо | UUID физического лица |
| book_number | СостояниеСтудентов, измерение ЗачетнаяКнига, наименование | номер зачетной книжки, равен логину Moodle |
| program_id | СостояниеСтудентов, ресурс УчебныйПлан | документ учебного плана, тот же идентификатор в dim/programs |
| group_code, faculty, study_form, basis | ресурсы Группа, Факультет, ФормаОбучения, Основа | наименования |
| gender, birth_date | ФизическиеЛица, реквизиты Пол и ДатаРождения | значения «Мужской», «Женский» |
| region | ФизическиеЛица, реквизит Регион (строка 50) | в тестовой базе реквизит отсутствует в конфигурации базы данных, поле пустое |
| hostel, privilege | источников нет | пустые |
| state | СостояниеСтудентов, ресурс Состояние | справочное поле текущего состояния, для обучения непригодно |

У студента с несколькими зачетными книжками остается одна запись.
Действующие студенты имеют состояние «Является студентом» или «Задолжник»;
остальные значения: «является выпускником», «Отчислен», «Находится в
академическом отпуске», состояния слушателей дополнительного образования.
Дата зачисления выводится приемником из fact/movements (приказы с типом
зачисления).

## 2. Программы (dim/programs)

Источник: документ УчебныйПлан.

| Поле | Источник | Примечание |
|---|---|---|
| program_id | ссылка на документ | UUID документа плана |
| title | реквизит Специальность | наименование вида «54.04.02 Декоративно-прикладное искусство и народные промыслы» |
| faculty, study_form | реквизиты Факультет, ФормаОбучения | наименования |
| year | реквизит УчебныйГод | наименование вида «2022 - 2025» |
| hours_per_credit | реквизит КоличествоЧасовВЗЕТ | норма часов в зачетной единице, почти во всех планах 36 |

В тестовой базе 3303 документа планов, записи плана есть у 2827 из них.

## 3. Дисциплины (dim/disciplines)

Источник: табличная часть ЗаписиУчебногоПлана документов учебных планов
и часть ЗЕТПоДисциплинам. Регистр сведений УчебныйПлан не используется:
его строковый ключ идентифицирует строку плана, а не документ (51 871
ключ на 3303 документа), связать их с программой нельзя.

| Поле | Источник | Примечание |
|---|---|---|
| program_id | ссылка на документ плана | соединяется с dim/students и dim/programs |
| discipline_id | Стр.Дисциплина | UUID дисциплины справочника, тот же идентификатор в fact/grades |
| discipline_title | Стр.Дисциплина, представление | |
| row_id | Стр.УникальныйИдентификаторСтроки | UUID строки плана, уникален |
| semester | Стр.ПериодКонтроля | «Первый семестр» и далее |
| load_type | Стр.Нагрузка | вид нагрузки или контроля: «Лекции», «Экзамен», «Зачет», «Курсовой проект» |
| unit, amount | Стр.ЕдиницаИзмерения, Стр.Количество | почти всегда часы |
| credits | ЗЕТПоДисциплинам.КоличествоЗЕТ | по учебному плану, узлу дисциплины (Стр.УникальныйИдентификатор) и периоду контроля |

Всего 275 278 строк планов с дисциплиной.

## 4. Движения контингента (fact/movements)

Источник: документ Приказы, табличная часть ОбщиеДанные (одна строка на
студента), проведенные документы в диапазоне дат приказа.

| Поле | Источник | Примечание |
|---|---|---|
| student_id, book_number | Стр.ФизическоеЛицо, Стр.ЗачетнаяКнига | |
| order_type | Стр.ТипПриказа | «Отчисление», «Перевод», «Выпуск», «Зачисление в вуз» |
| order_kind | Стр.ВидПриказа | «Отчисление по собственному желанию», «Перевод задолжников» |
| reason | Стр.Причина | в данных почти всегда пустое |
| analytics | Стр.Аналитика (справочник АналитикаТиповПриказа) | основание приказа, главный признак классификации |
| order_date | дата документа | |
| effective_date | Стр.ДатаОтчисления, иначе Стр.ДатаНачала | дата вступления в силу |
| program_id, group_code | Стр.УчебныйПлан, Стр.Группа | |
| entered_at | отсутствует | пустое |

Классификация отчислений строится по аналитике (указание заказчика
28.11.2026: смотреть поле аналитики либо наименование вида приказа).
Предлагаемое деление, подлежит утверждению заказчика:

| Класс | Значения аналитики |
|---|---|
| академические | «За академическую неуспеваемость», «Невыполнение учебного плана», «Как не прошедших ГИА» |
| финансовые | «Невыполнение условий договора об оказании платных образовательных услуг», «За нарушение условий договора» |
| нейтральные | «по собственному желанию», переводы, «в связи с окончанием университета», «В связи со смертью» и другие |

Отдельно учитываются типы приказов: отчисления слушателей
дополнительного образования (типы «Отчисление (выпуск) дополнительного
образования», «Отчисление (выпуск) ШАХТ») не относятся к студентам, хотя
их аналитика совпадает по формулировке. Полный перечень значений аналитики
возвращает GET /reference (ключ orderAnalytics).

## 5. Оценки (fact/grades)

Источник: документ Ведомость, табличная часть ДанныеПоАттестации,
проведенные документы в диапазоне дат контроля (дата занятия, при её
отсутствии дата документа).

| Поле | Источник | Примечание |
|---|---|---|
| student_id, book_number | Стр.ФизическоеЛицо, Стр.ЗачетнаяКнига | |
| program_id, discipline_id, discipline_title | Стр.УчебныйПлан, Ведомость.Дисциплина | дисциплина справочника |
| semester, control_type | Ведомость.ПериодКонтроля, Ведомость.ВидКонтроля | |
| attempt_no | порядковый номер ведомости по ключу студент, план, дисциплина, период | первая ведомость 1, пересдачи далее |
| grade | Стр.Отметка | наименование отметки |
| absent | отметка содержит «неявка» | |
| exam_date | дата контроля | |
| entered_at | отсутствует | пустое |

Отметки в ведомостях 2025/26 учебного года: «Зачтено» 2955, «Отлично»
2780, «Хорошо» 1972, «Неявка» 1347, «Удовлетворительно» 826, «Не зачтено»
64, «Неудовлетворительно» 14, числа стобалльной шкалы, служебные отметки
«Загрузил работу», «Не загрузил работу». Регистр ОтметкиЗачетныхКниг
хранит итоговую отметку строки зачетной книжки и не используется.

## 6. Задолженности (fact/debts)

Отдельного объекта в метаданных нет, задолженность выводится из оценок.
Отрицательные отметки: «Неудовлетворительно», «Не зачтено», «Неявка»,
отметка «2». Открытая задолженность закрывается следующей положительной
отметкой по тому же ключу (студент, учебный план, дисциплина, период
контроля). За 2025/26 учебный год: 6919 задолженностей, из них закрыто
3128. Числа стобалльной шкалы не классифицируются: порог
неудовлетворительной отметки нужно согласовать. Перезачет и
индивидуальные планы могут закрывать задолженность без ведомости.

## 7. Финансы (fact/finance)

Источник: документ ОплатаПоДоговорам, проведенные документы. Поля:
student_id, contract_id, amount, paid_date (дата документа), accrual_date
(ДатаОплатыПоГрафикуПлатежей), overdue_days, event_id.

В тестовой базе финансовых данных нет: 5573 документа оплат ни один не
проведен (даты с 20.08.2026 по 2032 год, плановые), регистры РасчетыПоДоговорам
и ПлатежныеОперации пусты, в графике платежей 10 962 записи с 2015 года.
Витрина finance возвращает пустой список. Решение заказчика: финансовые
события извлекать из базы бухгалтерии.

## 8. Нагрузка (fact/load)

Источник: та же часть ЗаписиУчебногоПлана, агрегация запросом по
документу и периоду контроля.

| Поле | Примечание |
|---|---|
| program_id, semester | документ плана и период контроля |
| n_disciplines | число дисциплин семестра |
| hours | сумма часов семестра |
| n_exams, n_tests, n_course_works | число дисциплин с экзаменом, зачетом, курсовой работой (проектом); виды отбираются по наименованию справочников ВидыКонтроля и ВидыНагрузки |
| hours_per_credit | КоличествоЧасовВЗЕТ документа плана |
| credits, credits_source | зачетные единицы семестра: из части ЗЕТПоДисциплинам (plan), при отсутствии вычисляются как часы, деленные на норму (calculated) |

Всего 8865 строк «план, семестр»: 8729 с зачетными единицами из плана,
136 вычисленных.

## 9. Поток событий (/events)

| kind | Источник | event_id | occurred_at |
|---|---|---|---|
| grade | Ведомость, строка ДанныеПоАттестации | grade:UUID ведомости:номер строки | дата контроля |
| debt_open | производная задолженность (п. 6) | debt-open:UUID ведомости:номер строки | дата возникновения |
| debt_closed | ведомость с положительной отметкой | debt-closed:UUID ведомости:номер строки | дата закрытия |
| payment | ОплатаПоДоговорам | payment:UUID документа | дата документа |

Идентификаторы производные от записей источника и не меняются при
повторной выгрузке. За февраль 2026 года 3433 события, все идентификаторы
уникальны.

## 10. Соответствие студент и зачетная книжка (/mapping/students-books)

Источник: срез СостояниеСтудентов на дату, все пары физлицо, зачетная
книжка, начальная зачетная книжка. Поля student_id, book_number,
student_state.

## 11. Ограничения

1. Дата внесения записи в источниках отсутствует: entered_at пустое,
   применяется запаздывание на стороне приемника (базовая постановка,
   п. 6.3).
2. Реквизиты Регион и Город справочника ФизическиеЛица есть в основной
   конфигурации, но сеансы их не видят: в тестовой базе конфигурация базы
   данных не приведена в соответствие с основной. Сервис выполняет запрос
   без региона.
3. Числовые отметки стобалльной шкалы не классифицируются.
4. Отчисления слушателей дополнительного образования попадают в общий
   поток приказов; приемник отбирает приказы студентов по типу приказа.
5. Зачисление в группу ведется документом ФормированиеКонтингента и
   приказами; принадлежность к группе на дату восстанавливается из
   СостояниеСтудентов (ресурс Группа) и истории приказов.
